## Overview

**ShadowCue**는 화면 녹화나 화면 공유 시 보이지 않는 macOS 전용 텔레프롬프터입니다.

유튜브 촬영, 화상 회의, 프레젠테이션, 라이브 스트리밍 등에서 자연스럽게 대본을 읽으면서도 시청자에게는 프롬프터가 전혀 보이지 않습니다.

### Key Features

- **스텔스 모드**: 화면 녹화/공유에서 창이 제외됨 (메뉴바에도 앱 이름이 뜨지 않음)
- **작업 상태 유지**: 대본·색상·글자 크기·속도·창 위치·단축키가 다음 실행에도 그대로 — 촬영 준비를 다시 하지 않아도 됨
- **대본 자동 저장**: 타이핑하면 바로 반영되고 파일로 보관됨 (Finder·git 으로 열람/백업 가능)
- **항상 최상위 표시**: 풀스크린 앱 위에서도 항상 보임
- **마크다운 지원**: 제목, 굵게, 기울임, 목록 등 마크다운 문법 렌더링
- **자동/수동 스크롤**: 트랙패드, 스크롤바, 단축키로 자유롭게 조작
- **글로벌 단축키**: 다른 앱에서도 프롬프터 제어 가능 (커스터마이징 가능)
- **완전 커스터마이징**: 글자 크기, 색상, 배경 투명도, 스크롤 속도, 행간
- **클릭스루 모드**: 프롬프터 뒤의 콘텐츠 클릭 가능
- **업데이트 확인**: 메뉴에서 새 버전 확인 가능

## Installation

### 방법 1: Release 다운로드 (권장)

1. [**최신 릴리즈 다운로드**](https://github.com/joonlab/ShadowCue-For-Mac/releases/latest)
2. 최신 zip 다운로드 후 압축 해제
3. `ShadowCue.app`을 **Applications** 폴더로 이동
4. **격리 속성 제거** — 이 앱은 Apple 공증(notarization)을 받지 않았습니다:
   ```bash
   xattr -cr /Applications/ShadowCue.app
   ```
5. 실행

> ⚠️ 4번을 건너뛰면 *"손상되었기 때문에 열 수 없습니다"* 가 나오고 **'그래도 열기' 선택지가 없습니다.**
> 악성 코드라서가 아니라, 개발자 서명·공증이 없는 앱에 macOS 가 붙이는 격리 표시 때문입니다.
> 소스가 전부 이 저장소의 `main.swift` 한 파일에 있으니 직접 확인하고 빌드하셔도 됩니다.

### 방법 2: 직접 빌드 (권장 — 격리 문제가 없습니다)

```bash
git clone https://github.com/joonlab/ShadowCue-For-Mac.git
cd ShadowCue-For-Mac

./build.sh            # build/ 에 universal 빌드 + 셀프테스트
./build.sh --install  # ShadowCue.app 번들까지 갱신

cp -R ShadowCue.app /Applications/
```

`build.sh` 는 아키텍처와 최소 OS 버전을 명시해 빌드합니다. `-target` 없이 `swiftc` 를 직접 쓰면
**빌드한 맥의 아키텍처·OS 버전이 그대로 박혀서** 다른 맥에서 실행되지 않습니다(v1.1 이 이 문제로
arm64·macOS 26 전용으로 배포됐습니다).

## Usage

### 기본 단축키

| 단축키 | 기능 |
|--------|------|
| `Ctrl + Option + Return` | 자동 스크롤 재생/일시정지 |
| `Ctrl + Option + ↑` | 위로 스크롤 |
| `Ctrl + Option + ↓` | 아래로 스크롤 |
| `Ctrl + Option + H` | 프롬프터 숨기기/보이기 |
| `Ctrl + Option + D` | 클릭스루 모드 전환 |
| `Ctrl + Option + .` | 스크롤 속도 증가 |
| `Ctrl + Option + ,` | 스크롤 속도 감소 |
| `Ctrl + Option + R` | 대본 처음으로 (재촬영용) |
| `Ctrl + Option + [` | 이전 섹션 (제목 단위) |
| `Ctrl + Option + ]` | 다음 섹션 |
| `Ctrl + Option + V` | 클립보드를 대본으로 교체 |
| `Ctrl + Option + /` | 단축키 목록 보기 |

> 모든 단축키는 설정에서 커스터마이징 가능하며, 바꾼 값은 다음 실행에도 유지됩니다.

> **v1.2 에서 재생 단축키가 `Ctrl+Option+Space` → `Ctrl+Option+Return` 으로 바뀌었습니다.**
> 한국어 환경의 macOS 는 "입력 메뉴에서 다음 소스 선택"(한/영 전환)에 `Ctrl+Option+Space` 를
> **기본으로 켜 둔 채 출고**되어, 재생이 안 되고 입력기만 바뀌는 문제가 있었습니다.

단축키가 안 먹으면 메뉴바 아이콘이 `☷⚠` 로 바뀌고, 설정 창의 해당 항목이 빨갛게 표시됩니다.
다른 앱이 그 조합을 이미 쓰고 있다는 뜻이니 설정에서 다른 조합으로 바꾸세요.

### 스크롤 조작

- **트랙패드**: 프롬프터 위에서 두 손가락 스크롤
- **스크롤바**: 오른쪽 스크롤바 드래그 (스크롤 시 자동 표시, 3초 후 숨김)
- **단축키**: 글로벌 단축키로 어디서든 조작 (이동 폭은 글자 크기에 비례합니다)

### 읽기 보조 (v1.2)

프롬프터 위에 얇은 보조 표시가 함께 뜹니다. 마우스 이벤트를 가로채지 않으므로 스크롤 조작에는
영향이 없습니다.

- **시선 밴드** — 화면 상단 38% 지점의 가로선. 카메라를 봤다가 시선을 돌려도 읽던 줄을 바로 찾습니다
- **상하 페이드** — 위아래를 살짝 눌러 지금 읽을 부분에 시선이 머물게 합니다
- **진행률 바** — 창 맨 아래 2px
- **남은 시간** — 자동 스크롤 중 우측 상단에 `남음 2:31` (현재 속도 기준 실제 잔여 시간)
- **상태 토스트** — 재생/일시정지, 속도 변경, 대본 끝 등을 화면 하단에 잠깐 표시.
  설정 창을 닫아 둔 채 단축키만 쓰는 상황을 위한 것입니다
- **클릭 통과 뱃지** — 클릭 통과가 켜져 있으면 해제 단축키와 함께 좌측 상단에 상시 표시.
  이 모드는 창을 클릭할 수도 스크롤할 수도 없으므로 탈출 방법이 항상 보여야 합니다

### 이어읽기

앱을 종료해도 어디까지 읽었는지 기억합니다. 재실행하면 그 위치에서 이어집니다.
처음부터 다시 찍을 때는 `Ctrl+Option+R`.

### 조작 바

프롬프터에 마우스를 올리면 하단에 조작 바가 나타납니다(재생·속도·글자 크기·처음으로·설정).
1.5초간 마우스를 치우면 사라집니다. 단축키를 외우지 않아도, 설정 창을 열지 않아도 됩니다.

### 창 배치

메뉴바 아이콘 → **창 크기** 에서 프리셋을 고를 수 있습니다.

| 프리셋 | 용도 |
|---|---|
| 작게 / 보통 / 크게 | 화면 중앙에 고정 크기 |
| **하단 띠** | 화면 아래쪽 가로 띠 — 카메라를 보면서 훑기 좋아 시선 이동이 가장 적습니다 |
| 화면 중앙 | 크기는 그대로 두고 위치만 |

창을 화면 가장자리 20px 안쪽까지 끌면 자동으로 딱 붙습니다(드래그를 멈춘 뒤에 붙으므로
움직이는 도중에 방해받지 않습니다).

### 대본 여러 개

메뉴바 아이콘 → **대본** 에서 대본을 전환하거나 새로 만들 수 있습니다. 전환하면 현재 대본은
자동 저장되고, 각 대본의 읽던 위치는 따로 기억됩니다.

### 목표 시간에 맞추기

"이 대본을 몇 분에 읽는다"가 정해져 있으면 설정 창의 **목표 시간** 에 분을 넣고
`속도 계산` 을 누르세요. 스크롤 속도를 거꾸로 계산해 넣어줍니다.
속도 한계(10~200)에 걸리면 실제 예상 시간을 알려줍니다.

### 유리 프롬프터 (반사 리그)

카메라 앞에 반투명 유리를 대고 쓰는 리그는 **거울에 비친 글자**를 읽으므로 좌우가 뒤집혀야 합니다.
설정 창의 **좌우 반전**을 켜세요(상하 반전도 있습니다). 대본만 뒤집히고 진행률·버튼·뱃지는
그대로라 조작에는 지장이 없습니다.

### 설정 이식·초기화

메뉴바 아이콘 → **설정 관리**:

- **설정 내보내기 / 가져오기** — 노트북과 데스크톱에 같은 세팅을 쓰고 싶을 때. JSON 파일입니다.
- **모든 설정 초기화** — 기본값으로 되돌립니다. **대본은 지워지지 않습니다.**

> 파일 열기/저장 대화상자는 별도 프로세스가 그려서 화면 캡처에 찍힙니다. 촬영 중에는 쓰지 마세요.

### 읽기 편하게 (설정 창)

- **최대 줄 너비** — 창을 넓히면 한 줄이 수십 자로 늘어져 줄 끝에서 다음 줄 머리를 못 찾게 됩니다.
  폭을 제한하면 글이 가운데로 모입니다. 프롬프터 가독성에서 가장 큰 변수입니다.
- **폰트** — 한글이 깨지지 않는 폰트만 목록에 나옵니다.
- **행간 / 자간** — 낭독 속도에 맞춰 조절하세요.
- **재생 전 3초 카운트다운** — 카메라 앞에서 자세를 잡을 시간이 필요할 때.

### 마크다운 지원

설정 창에서 마크다운 문법으로 텍스트를 입력하면 프롬프터에 렌더링됩니다:

| 문법 | 설명 |
|------|------|
| `# 제목` | H1 제목 (가장 큼) |
| `## 제목` | H2 제목 |
| `### 제목` | H3 제목 |
| `**굵게**` | 굵은 글씨 |
| `*기울임*` | 기울임꼴 |
| `~~취소선~~` | 취소선 |
| `` `코드` `` | 인라인 코드 |
| `- 항목` | 목록 |
| `1. 항목` | 번호 목록 |
| `> 인용` | 인용문 |
| `---` | 구분선 |

```bash
vtool -show-build /Applications/ShadowCue.app/Contents/MacOS/ShadowCue | grep minos
```

## How It Works

ShadowCue는 macOS의 `NSWindow.sharingType = .none` 속성으로 화면 캡처·공유에서 창을 제외합니다.
추가 드라이버나 시스템 개조 없이 OS 기본 기능만 씁니다. 앱은 메뉴바 전용(`LSUIElement`)으로 동작해
**녹화 화면의 메뉴바에도 앱 이름이 남지 않습니다.**

### ⚠️ 중요한 촬영 전에는 반드시 테스트 녹화로 확인하세요

이 은닉은 Apple 이 "화면 캡처 방지"를 위해 **보증하는 기능이 아닙니다.** Apple 개발자 지원은
공개적으로 *"there are no public APIs for preventing screen capture"* 라고 밝히고 있고,
이 동작을 버그로 접수한 사례도 있습니다. 즉 **OS 업데이트로 바뀔 수 있습니다.**

2026-08-02 기준 macOS 26.4 에서 `screencapture` 스틸·동영상과 ScreenCaptureKit(Zoom·OBS·Meet 이
쓰는 경로) 모두 은닉이 확인됐습니다. ScreenCaptureKit 은 자기 창 목록에 이 창을 그대로 가지고
있으면서도 픽셀에는 담지 않았습니다. 그래도 **중요한 촬영 전에는 1분만 투자해 직접 확인하시길**
권합니다 — 위에 적었듯 이건 Apple 이 보증하는 기능이 아닙니다:

1. 프롬프터를 띄우고 대본을 보이게 한다
2. `⌘⇧5` 또는 `screencapture -v ~/Desktop/test.mov` 로 10초 녹화
3. 녹화 파일을 재생해 **프롬프터와 메뉴바에 ShadowCue 가 없는지** 확인
4. 실제 사용할 도구(Zoom 화면 공유, OBS 등)로도 같은 확인

파일 열기/저장 대화상자는 별도 프로세스가 그리므로 은닉되지 않습니다. 촬영 중에는 열지 마세요.

## Changelog

### v1.2

**"촬영 준비를 매번 다시 하지 않아도 되게" 만든 판**

- **설정·대본 영속화** — 대본, 글자 크기, 색상, 배경 투명도, 스크롤 속도, 행간, 창 위치,
  커스텀 단축키가 다음 실행에도 유지됩니다. 이전에는 앱을 끄면 전부 초기화됐습니다.
- **대본 파일 저장** — `~/Library/Application Support/ShadowCue/scripts/` 에 마크다운으로
  보관되고 직전 세대 백업(`.bak`)도 남습니다. 타이핑하면 0.3초 뒤 프롬프터에 자동 반영됩니다.
- **스텔스 강화** — 메뉴바에 앱 이름이 노출되던 문제를 해결했습니다(`.accessory` 전환).
  컬러 패널·알림창 등 보조 창도 캡처에서 제외되고, 창 제목도 남기지 않습니다.
- **기본 재생 단축키 변경** (`⌃⌥Space` → `⌃⌥Return`) — 한국어 macOS 기본 단축키(한/영 전환)와
  충돌해 재생이 안 되던 문제.
- **자동 스크롤 수정** — 대본 끝에 도달하면 이제 실제로 멈춥니다(이전에는 정지 조건이
  수학적으로 도달 불가여서 되감으면 저절로 다시 흘러내려갔습니다). 창·슬라이더를 드래그하는
  동안에도 스크롤이 끊기지 않고, 프레임 누락도 보정합니다.
- **읽던 위치 유지** — 글자 크기를 바꾸거나 창 크기를 조절해도 맨 위로 튀지 않습니다.
- **마크다운 수정** — 한 줄에 여러 강조가 섞이면 앞쪽 강조가 사라지던 문제
  (`*기울임* 그리고 **굵게**`, 백틱 안의 별표 등).
- **단축키 실패 표시** — 다른 앱이 조합을 점유하면 메뉴바 `☷⚠` 와 설정 창 빨간 표시로 알립니다.
- **universal 바이너리 + 유효한 서명** — v1.1 은 arm64·macOS 26 전용으로 빌드되어 README 의
  "macOS 12 이상, Intel 지원" 표기와 달랐고, 서명 검증이 실패해 *"손상되었기 때문에 열 수 없습니다"* 가
  떴습니다. 이제 arm64+x86_64 / macOS 12+ 로 빌드되고 `codesign -v` 를 통과합니다.
- **읽기 보조 오버레이** — 시선 밴드, 상하 페이드, 진행률 바, 남은 시간, 상태 토스트,
  클릭 통과 뱃지. 마우스 이벤트는 전부 통과시킵니다.
- **호버 조작 바** — 마우스를 올리면 재생·속도·글자 크기·처음으로·설정 버튼이 나타납니다.
- **섹션 점프** (`⌃⌥[` / `⌃⌥]`) — 제목(`#`) 단위로 건너뜁니다.
- **대본 여러 개** — 메뉴바에서 전환·생성. 대본마다 읽던 위치를 따로 기억합니다.
- **클립보드 투입** (`⌃⌥V`) — 촬영 직전 다른 앱에서 복사한 대본을 창 하나 안 열고 바로 교체.
- **창 프리셋 + 가장자리 스냅** — '하단 띠' 배치 포함.
- **목표 시간 → 속도 자동 계산** — "8분에 읽기"를 넣으면 스크롤 속도를 역산합니다.
- **타이포그래피** — 최대 줄 너비 제한(가독성에 가장 큰 변수), 폰트 선택(한글 지원 폰트만),
  행간·자간. 제목 줄간격이 본문 행간에 끌려 과하게 벌어지던 문제도 수정.
- **재생 전 3초 카운트다운**(옵션), 클릭 통과 상태도 다음 실행에 복원.
- **미러 모드** — 유리 프롬프터용 좌우/상하 반전. 대본만 뒤집히고 조작 UI 는 그대로입니다.
- **단축키 치트시트** (`⌃⌥/`) — 현재 단축키 전체를 화면에 표시(등록 실패 항목도 함께).
- **설정 내보내기/가져오기/초기화** — 여러 대의 맥에 같은 세팅을 옮길 수 있습니다.
- **이어읽기** — 종료 후 재실행하면 읽던 위치에서 계속. `⌃⌥R` 로 처음으로 이동.
- 단축키 스크롤 이동 폭이 글자 크기에 비례합니다(48pt 에서 한 줄도 안 넘어가던 문제).
- 프롬프터 창의 신호등 버튼(닫기·최소화·확대)을 감췄습니다 — 캡처에 안 보이는 창이라
  실수로 누르면 앱이 사라진 것처럼 느껴집니다. `⌃⌥H` 로 숨기세요.
- 클릭스루 상태에서 투명도를 조절해도 "입력 통과 중" 표시가 유지됩니다.

#### v1.2 실기기 검증에서 고친 것 (2026-08-02)

실제로 녹화하고 조작해 보며 확인하는 과정에서 나온 수정입니다.

- **미러 반전이 첫 실행에 안 걸리던 문제** — 반전을 켜고 앱을 껐다 켜면 반전이 적용되지 않고,
  창을 한 번 리사이즈해야 그제서야 걸렸습니다. AppKit 이 레이어 지오메트리를 되돌리면서
  반전이 사라지는데 재적용 시점이 창 크기 변경에만 걸려 있던 탓입니다.
- **최소화·확대 버튼도 감췄습니다** — 닫기만 감춰져 있었습니다. 캡처에 안 보이는 창이라
  어느 버튼을 눌러도 "앱이 사라졌다"로 보이고, 특히 최소화는 메뉴바 전용 앱이라
  Dock 에 되돌릴 자리조차 없습니다.
- **치트시트 가독성** — 배경이 반투명해 뒤의 대본이 비쳐 읽기 어려웠습니다. 글자도 키웠습니다.

같은 검증에서 스텔스는 `screencapture` 스틸·동영상과 ScreenCaptureKit(Zoom·OBS 가 쓰는 경로)
모두에서 통과했습니다. 은닉만 끈 동일 빌드로 대조군을 만들어, 같은 방법으로 찍으면 대본이
그대로 보인다는 것도 함께 확인했습니다.
